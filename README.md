# Система управления факультативами

## Назначение
Приложение предназначено для автоматизации процесса управления факультативными курсами в университете. Оно позволяет студентам записываться на курсы, а преподавателям управлять списками групп и расписанием.

## Целевая аудитория
- Студенты, желающие записаться на интересующий их факультатив.
- Преподаватели, ведущие факультативные курсы.
- Администраторы, управляющие расписанием и категориями курсов.

## Предметная область
Учебный процесс в вузе. Факультатив — это курс, который студент выбирает дополнительно к основной программе. В системе хранится информация о студентах, преподавателях, курсах и записях на эти курсы.

## Основные сущности
- **Студент:** ФИО, группа (например, ЭФБО-02-24), email.
- **Преподаватель:** ФИО, email, специализация.
- **Курс (Факультатив):** Название, описание, преподаватель, максимальное количество студентов, расписание.
- **Запись на курс:** Связь между студентом и курсом, дата записи, статус (подтверждена/отклонена).

## Основные функции
- **Просмотр каталога курсов:** Студент может видеть все доступные факультативы с описанием и расписанием.
- **Запись на курс:** Студент может подать заявку на выбранный факультатив.
- **Управление записями:** Преподаватель может подтверждать или отклонять заявки студентов.
- **Просмотр своего расписания:** Студент видит список курсов, на которые он записан.
- **Добавление курсов:** Преподаватель/админ может создавать новые факультативы.

## План развития
На следующих этапах планируется:
- Разработка полноценного веб-приложения на Django.
- Подключение базы данных (PostgreSQL) для хранения сущностей.
- Реализация аутентификации и авторизации (студент, преподаватель, админ).
- Разработка REST API для взаимодействия с мобильными приложениями.
- Контейнеризация приложения с помощью Docker.
- Настройка CI/CD для автоматического тестирования и развертывания.
