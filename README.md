# Система управления факультативами

## Назначение
Автоматизация управления факультативными курсами: запись студентов, отмена, поиск, сортировка и статистика.

## Целевая аудитория
Студенты, преподаватели, администраторы вуза.

## Предметная область
Учебный процесс. Факультатив — дополнительный курс по выбору студента.

## Основные сущности
- **Студент:** id, ФИО, группа, email
- **Курс:** id, название, описание, преподаватель, max/current студентов, дата
- **Запись:** id, student_id, course_id, дата, статус (active/cancelled)

## Основные функции
1. Просмотр каталога курсов
2. Фильтрация по доступности
3. Поиск по названию/описанию
4. Сортировка (по названию, по местам)
5. Запись на курс
6. Отмена записи
7. Статистика (топ курсов, количество записей)
